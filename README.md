# Attendance Management System (AMS)

## Project Overview
The Attendance Management System is a web-based application developed to simplify and manage student attendance records. It provides separate access for Admin, Faculty, and Students, making attendance management more organized and efficient.

## Features
- **Admin:** Manage users and system records.
- **Faculty:** Mark and manage student attendance.
- **Student:** View personal attendance records and subject-wise attendance.
- **Attendance Tracking:** Maintain attendance records by subject and date.
- **Attendance Reports:** Generate attendance reports and calculate attendance percentages.
- **User Authentication:** Login and logout functionality.

## Technologies Used
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python, Flask
- **Database:** SQLite

## Installation and Setup

### 1. Clone the Repository
```bash
git clone https://github.com/YOUR-USERNAME/Attendance-Management-System.git
```

### 2. Open the Project Folder
```bash
cd Attendance-Management-System
```

### 3. Create a Virtual Environment
```bash
python -m venv .venv
```

### 4. Activate the Virtual Environment

**Windows:**
```powershell
.venv\Scripts\activate
```

### 5. Install Dependencies
```bash
pip install -r requirements.txt
```

### 6. Run the Application
```bash
python app.py
```

### 7. Open in Browser
Visit the local address displayed in the terminal, usually:

`http://127.0.0.1:5000`
